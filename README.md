## 🟢 免安装绿色版

**压缩包**：`Typora.Green.7z`

### 使用（就两步）

1. **解压整个文件夹**到任意位置（建议非系统盘）
2. **双击 `START-Typora.exe`** —— 启动 Typora，同时自动在桌面创建「Typora Green」图标

以后启动：双击桌面上的「Typora Green」即可。
（`START-Typora.bat` 是后备入口：万一 exe 被安全软件拦了，双击它效果一样。）

### 可选设置

双击 `SETUP.bat`，菜单：

| 选项 | 作用 |
|---|---|
| 1 | 重新创建桌面图标 |
| 2 | 注册 .md 文件关联（双击 Markdown 文件直接打开，设置一次永久生效） |
| 3 | 撤销全部（删图标、取消关联） |
| 4 | 立即启动 |

详细说明见压缩包内 `README-先看我.txt` 和 `使用说明.md`。

## 🔧 脚本版

**压缩包**：`typora-patcher-1.0.5.7z`

### 包内内容

| 文件/目录 | 说明 |
|---|---|
| `start.bat` | 启动器，双击运行 |
| `typora_crack.js` | 补丁主脚本（v1.0.5） |
| `node.js/` | Node.js 安装包（`.msi` 推荐 + `.zip` 便携备用） |
| `node_modules/` | 脚本依赖（已内置，首次运行免联网） |
| `发行说明.txt` | 包内说明 |

> 本包**不再附带 Typora 安装包**：去[官网](https://typora.io)下载任意版本安装即可。

### 使用步骤

1. **安装 Node.js** — 双击 `node.js/node-v24.18.0-x64.msi`（已装过可跳过）
2. **安装 Typora** — 官网下载任意版本安装，装完打开一次再关闭
3. **双击 `start.bat`**，按提示：
   - 选择 Typora 安装目录（自动检测，回车确认）
   - 输入机器码（Typora → 激活 → 输入序列号 → 离线激活，复制机器码）
   - 输入邮箱（随便填，格式对即可）

完成后打开 Typora 即为激活状态。

### 回滚还原

再次运行脚本 → 检测到已激活 → 输入 `Y` → 自动还原为官方原版。

## v1.0.5 更新说明

### 🆕 绿色版发布

完整 Typora 预先打好补丁，**激活指纹运行时自动匹配本机**——任何电脑解压即激活，无需机器码。

### 🛡️ 拦截 Typora 自动更新（重要修复）

实测 Typora 会**静默自动更新**：启动约 17 秒后检查更新 → 直接下载安装新版本 → 补丁被覆盖失效。这正是很多用户「第一天正常、第二天弹试用期剩余 X 天」的主因。

v1.0.5 在四个网络出口全部拦截更新检查与安装包下载，补丁不会再被洗掉。想升级 Typora：先回滚 → 装新版 → 重新打补丁。

### 🧬 激活指纹动态匹配

旧版激活信息绑定打包机器的指纹，换电脑校验不过。现在运行时自动取本机真实指纹填入，绿色版得以实现，脚本版同样受益。

### 沿用 v1.0.3 的修复

Typora 启动约 8 分 50 秒后的概率性「二次校验」会无条件吊销授权（运行中弹「试用 0 天」），v1.0.3 起已拦截该定时器，本版保留。

详细技术说明见 [CHANGELOG.md](CHANGELOG.md)。

## 常见问题

**Q：激活后过几天又弹「试用期剩余 X 天」？**
A：旧版脚本（v1.0.2 及更早）没拦截 Typora 自动更新，Typora 升级后补丁失效。**换 v1.0.5 绿色版**（推荐），或用 v1.0.5 脚本重跑一次。

**Q：绿色版双击 `START-Typora.exe` 闪退，或桌面没出现图标？**
A：确认解压完整（`app\resources` 子目录存在）；换个解压路径；检查杀毒软件是否拦截。若 exe 被杀软删了，改用 `START-Typora.bat`；图标没建出来可以 `SETUP.bat` 选 1 手动建（启动器每次启动也会自动自检补建）。

**Q：打开方式列表里没有 Typora Green？**
A：弹窗点「更多选项」→「在这台电脑上查找其他应用」→ 手动选 `app\Typora.exe`，选一次以后就一直在。

**Q：绿色版怎么升级新版本 Typora？**
A：绿色版已屏蔽自动更新。换新包：先 `SETUP.bat` 选 3 清理 → 删旧文件夹 → 解压新包。

更多问题见压缩包内说明文档。
