# Typora 激活脚本 - 操作说明

## 环境要求

- **操作系统**：Windows 7 及以上
- **Node.js**：需提前安装，下载地址 https://nodejs.org/zh-cn （选 LTS 版本，安装时保持默认选项即可）
- **Typora**：已安装（任意版本）

## 使用步骤

### 第一步：确认 Node.js

打开命令提示符（Win+R → 输入 cmd → 回车），输入：

```
node -v
```

如果显示版本号（如 `v18.x.x`），说明已安装，可继续。如果提示"不是内部命令"，请先去官网下载安装。

### 第二步：启动脚本

**方式一：双击 `start.bat`**

直接双击 `start.bat` 文件即可运行。如果没装 Node.js 会自动提示。

**方式二：命令行运行**

在脚本所在目录打开命令提示符，输入：

```
node typora_crack.js
```

首次运行会自动安装依赖，等待完成即可。

### 第三步：选择 Typora 路径

脚本会按以下顺序查找 Typora：

1. **缓存路径** — 如果你之前运行过，会提示是否使用上次的路径，按回车确认即可
2. **注册表路径** — 自动从系统检测，按回车确认即可
3. **文件夹选择窗口** — 以上都没找到时弹出，手动选择 Typora 安装目录
4. **手动输入** — 图形界面不可用时，手动输入路径

> 💡 选的目录里面要有 `Typora.exe` 才行

### 第四步：输入激活信息

按提示依次输入：

1. **机器码** — 打开 Typora → 帮助 → 我的许可证，复制机器码
2. **邮箱** — 随便填一个邮箱格式，如 `abc@123.com`

> 💡 首次输入后会缓存，下次运行自动填充，按回车即可

### 第五步：等待完成

脚本会自动执行：
- 关闭 Typora 进程
- 解包并备份文件
- 注入激活代码
- 写入注册表授权

完成后显示激活码，直接打开 Typora 即可使用。

## 已激活状态

如果再次运行脚本，会提示"检测到 Typora 已经被激活过"，可选择是否回滚还原为官方原版。

## 回滚还原

运行脚本 → 检测到已激活 → 输入 `Y` → 自动还原所有修改，恢复为官方原版。

## 常见问题

**Q：双击 start.bat 闪退？**
A：右键 start.bat → 编辑，确认路径正确。或直接用命令行运行查看报错。

**Q：提示"Node.js not found"？**
A：还没装 Node.js，去 https://nodejs.org/zh-cn 下载安装。

**Q：提示路径无效？**
A：确保选的是 Typora 的根安装目录（里面有 `Typora.exe` 的那个文件夹），不是子目录。

**Q：激活后 Typora 打不开？**
A：重新运行脚本选择回滚还原，然后检查 Typora 版本是否兼容。

**Q：想换一台电脑用？**
A：把 `typora_crack.js` 和 `start.bat` 复制过去，新电脑装好 Node.js，重新运行即可。
