============================================================
          Typora 绿色版 - 先看我（总说明）
============================================================

这个文件夹里有两个入口，各管一件事：

  START-Typora.exe  ← 日常启动（双击它就行）
  SETUP.bat         ← 可选设置（想折腾时才用）

  （START-Typora.bat 是后备入口：万一 exe 被杀毒软件拦了，
    双击它效果完全一样）

------------------------------------------------------------
怎么启动？
------------------------------------------------------------
  双击 START-Typora.exe。

  第一次双击会自动做两件事（不用你选任何东西）：
    1. 启动 Typora
    2. 在桌面和本文件夹里各创建一个「Typora Green」快捷方式

  以后启动 Typora：双击桌面上的「Typora Green」图标就行
  （再双击 START-Typora.exe 也一样）。

  启动器每次都会自检：快捷方式被删了、或整个文件夹被挪到别处，
  它会自动补建 / 改成新路径。

  ⚠ 例外：如果你用 SETUP.bat 选过 3（Remove everything），
    启动器就不再自动建图标了；想建回来用 SETUP.bat 选 1。

------------------------------------------------------------
想让「双击 .md 文件」直接用它打开？（可选，设置一次）
------------------------------------------------------------
  1. 双击 SETUP.bat
  2. 输入 2，回车（Register .md file association）
  3. 弹出的窗口里选 Typora Green
  4. 勾选「始终使用此应用打开」，点确定

  完成后，双击任何 .md / .markdown 文件都默认用它打开。

------------------------------------------------------------
SETUP.bat 的选项含义
------------------------------------------------------------
  1  Create desktop icon ........ 重新创建桌面快捷方式
                                  （图标被删了想找回时用）
  2  Register .md association ... 注册文件关联+图标
                                  （想要双击 .md 直接打开时用一次）
  3  Remove everything .......... 撤销全部：删图标、取消关联
                                  （不想用了/恢复原状时用）
  4  Start Typora now ........... 立即启动（和双击 START 一样）
  0  Exit ....................... 退出菜单

------------------------------------------------------------
卸载
------------------------------------------------------------
  1. 双击 SETUP.bat，输入 3（清理图标和文件关联）
  2. 直接删掉整个文件夹，不留垃圾

------------------------------------------------------------
其他说明
------------------------------------------------------------
  - 与已安装的官方版 Typora 互不冲突，可共存
    （列表里绿色版显示为 Typora Green，官方版保持原样）
  - 软件本体在 app 文件夹里，别改名、别拆散
  - 绿色版已屏蔽自动更新；换新版本 = 删旧文件夹、解压新包
  - 本工具仅供学习与个人研究使用，请支持正版
