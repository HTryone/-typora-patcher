# Typora 绿色版 - 使用说明

> **发行版本：v1.0.6**（对应压缩包 `Typora.Green.7z`）
> **基于的软件版本：Typora 1.14.10**（Windows x64；本包内置的就是这个版本，不需要另装 Typora）
>
> 「发行版本」是本工具的补丁版本，「Typora 1.14.10」是打补丁的那个 Typora 原生版本，两者不要混。

## 文件夹里有两个入口

| 入口 | 作用 |
|---|---|
| **START-Typora.exe** | 日常启动（双击它就行） |
| **SETUP.bat** | 可选设置菜单（想折腾时才用） |

> 本包只有一个启动入口，没有 .bat 后备；exe 若被安全软件拦截，请把它加入白名单。

## 🚀 启动

双击 **START-Typora.exe**。

**第一次双击会自动做两件事**（不用选任何东西）：
1. 启动 Typora
2. 在**桌面**和**本文件夹**里各创建一个「Typora Green」快捷方式

以后再双击启动器时，它会顺手自检：**快捷方式被删了、或者整个文件夹被挪到别处了，就自动补建 / 改成新路径** —— 不用手动折腾。

> ⚠️ 唯一注意：整个文件夹必须放在一起，解压到哪都行，但别拆散。

## 想让「双击 .md 文件」直接用它打开？（可选，设置一次）

1. 双击 `SETUP.bat`
2. 输入 **2**（Register .md file association），回车
3. 弹出的窗口里选 **Typora Green**
4. 勾选 **「始终使用此应用打开」**，点确定

完成后，双击任何 `.md` / `.markdown` / `.mdown` / `.mkd` 文件都默认用它打开。

## SETUP.bat 选项含义

| 选项 | 含义 | 什么时候用 |
|---|---|---|
| 1 Create desktop icon | 重新创建桌面快捷方式 | 图标被删了想找回 |
| 2 Register .md association | 注册文件关联 + 图标 | 想双击 .md 直接打开（用一次） |
| 3 Remove everything | 撤销全部：删图标、取消关联（启动器也不再自动补建图标，直到你用 1/2 重新建） | 不想用了/恢复原状 |
| 4 Start Typora now | 立即启动 | 排查问题时 |
| 0 Exit | 退出菜单 | — |

## 与官方版冲突吗？

不冲突，可共存。绿色版显示为 **Typora Green**，官方版保持原样。
想切换默认：右键 md 文件 → 打开方式 → 选择其他应用里选另一个。

## 卸载

1. 双击 `SETUP.bat`，输入 **3**（清理图标和文件关联）
2. 直接删掉整个文件夹，不留任何残留

## 常见问题

**Q：双击 START-Typora.exe 或 Typora.exe 闪退？**
A：确认解压完整（`app\resources` 子目录存在）；换个解压路径；检查杀毒软件是否拦截——exe 被拦就先加入白名单。

**Q：exe 被杀毒软件报毒/删掉了？**
A：这是没有代码签名的程序常见的误报。把整个文件夹（或 `START-Typora.exe`）加进白名单即可。

**Q：双击 START-Typora.exe 了，但桌面没出现图标？**
A：先确认是不是之前用 `SETUP.bat` 选过 **3（Remove everything）** —— 那之后启动器就不再自动建图标了，用 `SETUP.bat` 选 **1** 建回来即可。正常情况下启动器每次启动都会自检，图标被删或文件夹被挪动都会自动补建。

**Q：桌面图标怎么变成白色文件样式了？**
A：图标缓存没刷新，按 F5 刷新桌面即可；实际快捷方式指向的是 Typora 的 T 字图标。

**Q：双击 .md 没反应或每次都弹选择框？**
A：重跑 `SETUP.bat` 选 2，弹窗里记得勾选「始终使用此应用」。

**Q：打开方式列表里没有 Typora Green？**
A：弹窗点「更多选项」→「在这台电脑上查找其他应用」→ 手动选 `app\Typora.exe`，选一次以后就一直在。

**Q：想升级新版本？**
A：绿色版已屏蔽自动更新。换新包：先 `SETUP.bat` 选 3 清理 → 删旧文件夹 → 解压新包 → 重新双击 START。

## 本版更新（v1.0.6）

- **修复：别人电脑上显示「未激活 + 15 天试用」** —— 旧版绿色包只有打包机自己能用，现在任何电脑首次启动即激活。
- **启动入口换成 `START-Typora.exe`** —— 不再依赖 PowerShell 建快捷方式，出错会明确弹窗；原来的 `.bat` 入口已移除，只保留 exe。
- **图标自愈** —— 桌面图标被删、或整个文件夹挪到别处，下次双击启动器会自动补建/改指向。
- 其余与 v1.0.5 一致（已屏蔽自动更新、已拦截运行中的二次校验）。
